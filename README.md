# husseinhassan_portfolio

A one-page 3D portfolio website built for **Hussein Hassan**, Dental Billing Specialist & Healthcare Virtual Assistant.

Inspired by luxury award-winning Framer dark-mode templates, featuring an interactive 3D WebGL light streak shader against a pure pitch-black background, 3D tilt cards, interactive 3D dental crystal model, and dedicated healthcare revenue cycle content.

## 🚀 Quick Start in VS Code

1. **Open in VS Code**:


4. **Production Build**:
   ```bash
   npm run build
   ```

5. **Preview Production Build**:

## 🎨 Visual & 3D Features

- **Pure Black Canvas**: Pure `#000000` pitch black background without background photos.
- **Dynamic 3D Colored Rays**: WebGL & Three.js shader reproducing the luminous cyan/azure light streak merging into sunset warm amber/gold, responsive to mouse position.
- **Interactive 3D Floating Dental Crystal**: Rotatable, draggable 3D geometric tooth model with glowing wireframe & glass refraction in Three.js.
- **3D Tilt Perspective Cards**: Skill, Experience, and Certification cards tilt dynamically in 3D perspective with specular glare that follows cursor coordinates.
- **Interactive Trailing Glowing Cursor**: Smooth physics cursor with particle halo.
- **Framer-style Giant Typography**: Massive bold display header **HUSSEIN HASSAN** at the base of the hero.
- **Web Audio Micro-interactions**: Futuristic subtle audio clicks and chimes (with mute toggle in navbar).

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite 5
- **Styling**: Tailwind CSS + Custom Dark Glow utilities
- **3D & Shaders**: Three.js (WebGL Shader Material, BufferGeometry, Physical Materials)
- **Icons**: Lucide React
- **Audio**: Native Web Audio API Synthesizer
